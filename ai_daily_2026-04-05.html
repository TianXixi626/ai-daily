1Apple 批准 Nvidia eGPU 驱动：M 系列 Mac 首次支持外接显卡
开发者Apple 正式批准 Tiny Corp 开发的驱动程序，允许 Nvidia 和 AMD eGPU 在 ARM Mac（M1/M2/M3/M4）上运行。此前使用 Nvidia eGPU 需要禁用系统完整性保护（SIP），安全风险极高。该驱动专为大模型（LLM）推理设计，非游戏用途。这意味着 Mac 生态的 AI 开发者终于能利用 Nvidia GPU 算力本地跑大模型，不再受限于 Metal 和 Apple Silicon 的 VRAM 天花板。历史性突破。

3微软开源 Agent Governance Toolkit
安全开源 AI Agent 安全工具包，防御 10 种关键攻击类型：目标劫持（Goal Hijacking）、记忆中毒（Memory Poisoning）、流氓 Agent（Rogue Agents）等。拦截响应时间 <0.1ms，可与现有 Agent 框架即时集成。发布背景：97% 的企业预计今年会发生重大 AI Agent 安全事件。当 Agent 开始操作真实业务（订机票、执行交易、管基础设施），没有安全治理就是敞开的大门。这是 Agent 从"能跑"到"能安全地跑在生产环境"的关键基础设施。

6LLM Wiki：超越 RAG 的持久化知识库新范式
